# Relay Desk

Relay Desk — внутренний сервис-деск для сотрудников компании. Через него сотрудники заказывают корпоративные услуги, сообщают о проблемах и находят инструкции, а команда поддержки управляет очередями, сроками SLA и загрузкой специалистов.

Репозиторий используется как честный учебный frontend-sandbox, но приложение развивается как единый продукт с устойчивой предметной областью, архитектурными решениями и историей изменений. Relay Desk и все показанные организации, сотрудники и обращения вымышлены.

## Что уже есть в продукте

- рабочая сводка с показателями, очередями и загрузкой команды;
- единая очередь заявок с поиском и фильтрами;
- создание заявки через доступную форму;
- детальная карточка с рабочей перепиской, внутренними заметками, редактируемыми свойствами, автором и историей;
- каталог корпоративных услуг;
- база знаний для самообслуживания сотрудников;
- управление командой и зонами ответственности;
- отчёты по обращениям, SLA и качеству поддержки;
- асинхронный слой данных с отменой запросов и явными loading/error/empty-состояниями;
- адаптивная навигация и базовая доступность интерфейса.

## Стек

- React 19 и TypeScript
- React Router
- Vite
- Vitest и Testing Library
- Oxlint

Стек намеренно остаётся небольшим. Новая зависимость должна решать конкретную продуктовую или инженерную проблему.

## Локальный запуск

```bash
npm install
npm run dev
```

Vite выведет локальный адрес приложения, обычно `http://localhost:5173`. Не открывайте `index.html` напрямую через `file://`: исходные модули приложения должны обрабатываться dev-сервером.

Текущая frontend-реализация хранит созданные и изменённые заявки только в памяти вкладки. После полного обновления страницы возвращаются исходные демонстрационные данные. Это явная граница baseline, а не production-хранилище.

## Проверки

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

Тот же набор выполняется в CI для pull request и основной ветки.

## Карта репозитория

```text
src/
  api/          клиентская граница данных
  components/   общие компоненты и каркас приложения
  data/         локальные данные для текущего frontend-стенда
  domain/       типы и отображение понятий предметной области
  hooks/        общие React-хуки
  pages/        страницы продуктовых разделов
  test/         настройка тестовой среды
docs/
  architecture/ архитектурные решения
  product/      продуктовый контекст и терминология
```
