# Правила работы с репозиторием

- Развивайте Relay Desk как единый продукт, а не набор разрозненных упражнений.
- Сохраняйте пользовательские изменения и состояние Git. Не сбрасывайте, не удаляйте и не переписывайте их без явного разрешения.
- Ограничивайте изменения рамками активного тикета и явно фиксируйте продуктовые допущения.
- Используйте семантическую разметку, доступные взаимодействия, адаптивное поведение и явные состояния загрузки, отсутствия данных, ошибки и успеха.
- Добавляйте зависимости только при наличии текущей продуктовой потребности и документируйте значимые архитектурные решения.
- Выполняйте проверки, соответствующие изменению. Полный набор: `npm run typecheck`, `npm run lint`, `npm test` и `npm run build`.
