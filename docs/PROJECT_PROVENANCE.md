# Происхождение baseline

Relay Desk — вымышленное приложение внутри учебного frontend-sandbox. Оно не является продуктом реальной компании и не создавалось реальной командой сотрудников.

Исходный baseline приложения, тестов и документации подготовлен OpenAI Codex 1 ноября 2026 года по поручению владельца проекта и на основе его проектного манифеста. Имена, организации, обращения и показатели внутри интерфейса являются демонстрационными данными.

Последующие изменения должны сохранять фактическое авторство через обычную Git-историю. Нельзя приписывать человеку сгенерированный baseline, создавать вымышленных человеческих авторов или представлять учебный процесс как опыт работы в реальной компании.

Публичный репозиторий и внешние ресурсы в рамках подготовки baseline не создавались.
